# DevMatch Account Creation Form

DevMatch is a responsive and accessible account creation form for developers.

The form allows users to create a developer profile, describe their technical skills and select their work preferences.

## Project Requirements

This project includes:

- Text inputs
- Textareas
- Dropdown menus
- Radio buttons
- Checkboxes
- File upload
- Range slider
- Date pickers
- Native HTML form validation
- Accessible labels and help text
- Keyboard navigation
- Visible focus states
- Semantic HTML elements
- ARIA attributes
- Responsive mobile design

## Technologies Used

- HTML5
- CSS3

No JavaScript, external libraries or frameworks were used.

## Form Sections

### 1. Account Setup

Users provide account information such as:

- Full name
- Username
- Email address
- Phone number
- Password
- Date of birth
- Profile photo

### 2. Developer Profile

Users provide professional information such as:

- Primary developer role
- GitHub profile
- Portfolio website
- Experience level
- Technologies
- Developer bio

### 3. Preferences and Availability

Users select:

- Opportunity types
- Preferred working model
- Weekly availability
- Preferred start date
- Time zone
- Communication preference

## Accessibility

The form includes:

- Visible labels for form controls
- Fieldset and legend elements for related controls
- Help text connected with `aria-describedby`
- Visible keyboard focus indicators
- Native HTML validation
- Accessible colors
- Touch-friendly form controls

## Responsive Design

The layout uses two columns on larger screens and changes to one column on mobile devices.
